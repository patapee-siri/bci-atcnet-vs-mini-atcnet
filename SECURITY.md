# Security Policy

## Scope

This repository is a research and portfolio project (EEG motor imagery classification) and is not
deployed as a production service. It does not handle user accounts, credentials, or personal data.
The dataset used (BCI Competition IV-2a) is a public, anonymized benchmark and is not included in
this repository.

## Supported Versions

Only the latest commit on the `main` branch is maintained. No versioned releases are published.

## Reporting a Vulnerability

If you find a security issue, for example a vulnerable dependency listed in `requirements.txt` or
unsafe handling of files in the training scripts, please report it privately rather than opening a
public issue:

- Use GitHub's "Report a vulnerability" option under the repository's Security tab, or
- Contact the repository owner through the email listed on their GitHub profile.

Please include a description of the issue and steps to reproduce it. Reports are typically
acknowledged within a week. Valid issues will be addressed as soon as practical, and reporters will
be credited unless they prefer to remain anonymous.
